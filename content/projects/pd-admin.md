# PD Admin

## Problem Statement

1. When setting up and configuring Professional Learning, customers need an accessible and easy way to change configurations and settings so that they have control over their own product. Currently, customers need to reach out to services to change simple configurations which causes wasted time, for both customers and PowerSchool, and customer frustration.
2. When using Professional Learning in conjunction with other PS products, customers need a consistent user experience so that they can use PowerSchool products to their fullest potential and are satisfied with the product. Currently, Professional Learning’s inconsistent (with other PS products) user experience causes frustrated and worse off users.
3. When using Professional Learning, customers need a modern user experience so that new customers can easily adopt the product and recognize design patterns. Currently, Professional Learning’s outdated user experience causes frustrated and worse off users.
4. When using Professional Learning, customers need a streamlined user experience so that they can use PowerSchool products to their fullest potential and are satisfied with the product. Currently, Professional Learning’s wonky and subpar user experience causes frustrated and worse off users.
    1. This problem only exists for some features! We will decide to pursue/not pursue solving this problem on a feature-by-feature basis.

## Key Outcomes

**Services spend less time with customers**

Analysis of implementation billable hours (internal) in 2021 - legacy vs. PD Admin customers (Salesforce)

*Our time to implement via hours decreases 25%*

**Support spends less time with customers**

Time analysis (PD Admin customers vs. legacy customers) of cases per customer for PL

*65% decrease in support cases*

**Customers feel are in control of their product**

Used Survey Questions

When answering “How easy is it to make changes…” between 1 (Really Hard) and 5 (Really Easy)

- Legacy Customers Avg: 2.54
- PD Admin Customers Avg: 3.125
- ***23% increase of control***

When answering “Do you feel like you have the ability to change this Professional Learning product to work for you district?”

- Legacy Customers: 36% Yes, 64% No
- PD Admin Customers: 66% Yes, 34% No
- ***30% increase of control***
